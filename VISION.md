# Vision: okgame (C++)

## The Goal
The ultimate goal of `okgame` is to create the definitive, high-performance, cross-platform reference implementation of the "unified puzzle engine." It aims to support EVERY puzzle game ever created by allowing users to define their own rules, blocks, and pieces.

## Core Foundational Concepts
- **Universal Puzzle Logic:** A data-driven engine where `GameType` defines the mechanics (randomizers, gravity, garbage rules).
- **Cross-Platform Parity:** 1:1 synchronization and parity between C++, Java (LibGDX), and Web (TypeScript) clients.
- **High-Frequency Synchronization:** Frame-perfect state synchronization for competitive multiplayer.
- **Extensibility:** Support for custom visualizers (projectM), Lua scripting, and Libretro cores.

## User-Satisfaction Design
- **Instant Response:** Zero-latency input handling using SDL3.
- **Visual Excellence:** Modernized OpenGL shaders and seamless background visualizer integration.
- **Global Community:** Unified matchmaking and leaderboards across all platforms.
